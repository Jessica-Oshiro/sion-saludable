# Sión Saludable — Sitio Web

## Descripción
Sitio web oficial de Sión Saludable, emprendimiento de productos naturales, panificados artesanales y comidas caseras saludables con base en Liniers, Buenos Aires.

## Estructura del proyecto
- index.html — Página de inicio
- catalogo.html — Catálogo completo con filtros y carrito
- contacto.html — Información de contacto y cómo funciona
- css/style.css — Estilos globales
- js/products.js — Base de datos de productos
- js/main.js — Lógica del carrito, filtros y renderizado

## Tecnologías
- HTML5, CSS3, JavaScript vanilla
- Google Fonts (DM Sans)
- Deploy en Vercel vía GitHub

## Variables clave
- Número de WhatsApp: definido en js/main.js como WA_NUMBER
- Colores principales: verde #2D5016, dorado #C49A0A, fondo #FAFAF8
- Tipografía: DM Sans (títulos y cuerpo)

## Cómo correr localmente
Abrir index.html directamente en el navegador o usar Live Server en VS Code.

## Notas importantes
- Ningún producto de elaboración propia lleva claim "sin TACC" por riesgo de contaminación cruzada en cocina doméstica
- Los productos de viandas y pastas se muestran como "consultar disponibilidad"
- El carrito deriva directamente a WhatsApp, no procesa pagos online
